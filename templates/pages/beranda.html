Cara Kerja Nutri-Guard AI

Proses analisis dimulai dari profil pengguna sampai sistem menghasilkan Nutri-Score dan rekomendasi konsumsi.

01

Isi Profil

Pengguna mengisi data fisik untuk membantu menghitung kebutuhan dan batas konsumsi personal.

02

Pindai Label

Foto Tabel Informasi Nilai Gizi diproses menggunakan Gemini AI API untuk membaca parameter nutrisi.

03

Prediksi Nutri-Score

Random Forest memproses parameter nutrisi untuk mengklasifikasikan produk ke grade A sampai E.

04

Rekomendasi

Forward Chaining mengevaluasi gula, batas personal, dan Nutri-Score untuk menghasilkan status konsumsi.

Fokus Sistem

Nutri-Guard AI tidak bergantung pada database nama produk atau merek. Proses utama sistem menggunakan parameter yang terbaca dari Tabel Informasi Nilai Gizi. Produk baru tetap dapat dianalisis selama label gizinya dapat terbaca dengan jelas.
